# 社会 一問一答 — 知識の冒険

静的な社会科の学習RPGです。`index.html` だけで開けます。背景・敵・デザインをHTML内に埋め込んでいるため、別のフォルダにコピーしても表示できます。ビルドは不要です。オンライン時はGoogle Fontsを使用し、オフラインでは端末のフォントを使用します。

## RPGの画面

- タイトルの「冒険の書を開く」から冒険の準備へ進みます。
- 出題範囲と問題数を選び、「冒険に出発する」で学習を始めます。
- 左に敵とHP、右に自キャラ・職業・レベル・装備中のアビリティ、その下に広い問いのウィンドウを表示します。
- 頭の中で答えて「こたえる · 答えを見る」。答えを確認して「正解 · こうげき」または「復習 · おぼえる」を選びます。自己採点の仕組みです。
- 職業、学習間隔、クエスト、バックアップは従来の仕組みを引き継ぎます。保存するキーを変更していないため、同じURL・ブラウザなら記録が残ります。

## 素材

背景・敵4種は本変更用にImageGenで生成したオリジナル画像です。既存キャラクター画像は維持しています。既存ゲームのロゴ・敵画像・画面素材は使用していません。

- `assets/sky-realm.png`: 浮島・古城・滝・石のテラスの背景。
- `assets/realm-enemies.png`: 森の精、夜のコウモリ、石の番人、竜の2×2透過スプライト。
- `assets/rpg-theme.css`: レスポンシブUI、金縁ウィンドウ、スプライト表示。

ローカル確認は `index.html` をブラウザで直接開いてください。学習記録は同じブラウザ・同じ場所で続けて使用し、移動前にはバックアップを取ると確実です。データには既存の授業開放日が設定されています。

`assets/` は編集用の元素材です。素材やCSSを変更したら `python scripts/embed-assets.py` でHTMLへの埋め込みを更新してください。配布には `index.html` だけで十分です。
